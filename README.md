## 🎮 Descrição do Jogo
**Delivery Runner** é um jogo do género *Endless Runner*, inspirado em títulos como Subway Surfers.  
O jogador controla um estafeta que corre automaticamente pela cidade, desviando-se de obstáculos, mudando de faixa e apanhando pizzas para aumentar a pontuação.

O objetivo é sobreviver o máximo de tempo possível enquanto recolhe o maior número de pizzas.

---

## 🕹️ Jogabilidade

### **Controlo do Jogador**
- **A** ou **←** — Mover para a faixa da esquerda  
- **D** ou **→** — Mover para a faixa da direita  
- **Espaço** — Saltar  
- O jogador corre automaticamente para a frente

### **Objetivo**
- Recolher pizzas para aumentar a pontuação  
- Evitar obstáculos  
- Sobreviver o máximo de tempo possível

### **Regras**
- Se o jogador colidir com um obstáculo → **Game Over**  
- A velocidade aumenta gradualmente ao longo do tempo  
- O jogo começa com um **countdown 3-2-1-GO** antes do movimento iniciar

## 📂 Como Abrir o Projeto

1. Abrir o **Unity Hub**
2. Clicar em **Open**
3. Selecionar a pasta do projeto (a pasta que contém a pasta `Assets/`)
4. Abrir com a versão **6000.3.9f1**
5. Carregar a cena principal:  
   `Assets/Scenes/MainScene.unity`
6. Clicar em **Play** para iniciar o jogo
