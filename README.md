## 🎮 Descrição do Jogo
**Delivery Runner** é um jogo do género *Endless Runner*, inspirado em títulos como Subway Surfers.  

O jogador controla uma personagem que corre automaticamente pela cidade, desviando-se de obstáculos, mudando de via e apanhando pizzas para aumentar a pontuação.

O objetivo é ajudar o Sr. Fausto, que é um reformado que voltou às ruas como estafeta para superar a crise. Tem como finalidade ajudá-lo a sobreviver ao caos da cidade, entregando o máximo de pizzas possível para garantir o seu sustento.

---

## 🕹️ Jogabilidade

### **Controlo do Jogador**
- **A** ou **←** — Mover para a via da esquerda  
- **D** ou **→** — Mover para a via da direita  
- **Espaço** — Saltar  
- O jogador corre automaticamente para a frente

### **Objetivo**
- Recolher pizzas para aumentar a pontuação  
- Evitar obstáculos  
- Sobreviver o máximo de tempo possível

### **Regras**
- Se o jogador colidir com um obstáculo → **Perdeu**  
- A velocidade aumenta gradualmente ao longo do tempo  
- O jogo começa com uma contagem descrescente **3-2-1-Começou** antes do movimento iniciar
